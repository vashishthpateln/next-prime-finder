# Next Prime Finder
A simple Python program that find the first prime number greater than an integer entered by the user.

## How it works
1. Prompts the user to enter an integer.
2. Checks consecutive integers to determine whether they are prime. 
3. Returns the first prime number greater than the original input. 

## Concepts used
- Python functions
- Loops and conditional statements
- List comprehensions
- The  `itertools` module
- Modular programming

## How to run
Requires Python 3. 

Run the following command in your terminal:
`python main.py`
